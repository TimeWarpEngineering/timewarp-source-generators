# FileLengthAnalyzer (TWA0038)

## Overview

Reports a C# file longer than the line limit. The default is 500. The count matches `wc -l`: a trailing line break does not add a line.

This rule moved from `TimeWarp.Architecture.Analyzers`. The id is still **TWA0038**. It ships enabled. A repo that treats warnings as errors and does not want the limit sets the severity to `none`.

## Rule Details

- **Rule ID**: TWA0038
- **Category**: Maintainability
- **Default Severity**: Warning (enabled)
- **Message**: File '{0}' has {1} lines, over the {2}-line limit; extract a responsibility into its own type

```ini
[*.cs]
dotnet_diagnostic.TWA0038.severity = warning
dotnet_diagnostic.TWA0038.max_lines = 500
```

`dotnet_diagnostic.TWA0038.max_lines` overrides the default when the value is a positive integer.

## Not reported

- Generated code: an `// <auto-generated` header, `*.g.cs`, `*.Designer.cs`, `*.generated.cs`, or `generated_code = true`
- Paths under an `obj/` or `goldens/` directory

## Suppression

```csharp
#pragma warning disable TWA0038
```

```ini
dotnet_diagnostic.TWA0038.severity = none
```
