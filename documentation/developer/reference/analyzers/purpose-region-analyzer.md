# PurposeRegionAnalyzer (TWA0004)

## Overview

Every non-generated C# file needs a `#region Purpose` block. A one-line comment inside the region is enough. Placement anywhere in the file counts. A `#region Design` block does not satisfy the rule.

This rule moved from `TimeWarp.Architecture.Analyzers`. The id is still **TWA0004**.

## Rule Details

- **Rule ID**: TWA0004
- **Category**: Documentation
- **Default Severity**: Warning (enabled)
- **Message**: File '{0}' has no '#region Purpose' block; add one (a single // line suffices) stating what the file is for

```ini
[*.cs]
dotnet_diagnostic.TWA0004.severity = warning
```

`timewarp-state` sets this severity to `error`.

## Not reported

- Generated code: an `// <auto-generated` header, `*.g.cs`, `*.Designer.cs`, `*.generated.cs`, or `generated_code = true`
- A file whose root has no token (trivia only)

## Suppression

```csharp
#pragma warning disable TWA0004
```

```ini
dotnet_diagnostic.TWA0004.severity = none
```
